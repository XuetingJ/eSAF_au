# eSAF_au: dynamic techno-economic model of Australian eSAF production, 2025–2050

Code and data for:

> *Global component learning and Australian conditions in the dynamic production costs of electro-sustainable aviation fuel.* (manuscript in preparation)

The model calculates the annual plant-gate production cost of electro-sustainable aviation fuel (eSAF) from an
alkaline-electrolysis – reverse-water-gas-shift – Fischer–Tropsch (AEL–RWGS–FT) plant in Australia, for
81 scenario combinations over 26 years (2,106 case-years). It decomposes between-case cost variation into local
and global-learning effects and runs the accounting-boundary tests reported in the paper.

## Quick start

```bash
git clone https://github.com/XuetingJ/eSAF_au.git
cd eSAF_au
pip install -r requirements.txt
python scripts/run_all.py                      # results  -> outputs/
python scripts/make_figures.py                 # figures  -> figures/
python verification/check_reported_values.py   # checks every headline value in the paper
```

Python 3.10 or later; the full run takes a few seconds.

## Model

For each year *t* and scenario case, the plant-gate cost (A$2026 per kg neat eSAF) is

```
C_t = (CRF_t · K_t + FOM_t + E_t + C_CO2,t − B_t) / Q_t
```

| Term | Meaning |
|---|---|
| `K_t` | Installed capital: alkaline electrolyser + RWGS/FT/upgrading + balance of plant (BOP) |
| `CRF_t` | Capital-recovery factor at the real WACC over a 30-year life |
| `FOM_t` | Fixed operations and maintenance, 3% of installed capital per year |
| `E_t` | Purchased electricity: electrolyser load plus cooling and syngas compression |
| `C_CO2,t` | Procured CO₂ at a levelised capture cost |
| `B_t` | Diesel and naphtha co-product credit |
| `Q_t` | Annual neat-eSAF output (20.22 million kg) |

Electrolyser and synthesis capital costs follow global experience curves with cost floors; electrolyser
electricity use and the CO₂ price follow common trajectories. The 81 cases cross four three-level factors:

| Factor | Levels |
|---|---|
| Australian electricity path | Low / Central / High |
| Real WACC | 3% / 7% / 10% |
| Electrolyser CAPEX learning rate | 5% / 13.2% / 18% per doubling |
| FT CAPEX learning rate | 0% / 5% / 10% per doubling |

**CO₂ boundary (screening assumption).** CO₂ is assumed to be procured at the plant fence from a co-located point
source, dried and compressed to at least process pressure, at the CSIRO levelised capture cost (A$82 t⁻¹, falling to
a A$54 t⁻¹ floor). The reference process's own capture (4.950 MW) and CO₂-compression (1.145 MW) loads are therefore
excluded from plant electricity. `esaf_model.LEGACY` restores them (the earlier accounting; not a costed on-site
capture design).

## Input sources

Process quantities: Cahyono et al. (2026), *Applied Energy* 424, 128439. Electrolyser installed cost: IEA *Global
Hydrogen Review 2025*, Assumptions Annex. CO₂ cost: CSIRO (2021) *CO₂ Utilisation Roadmap*, Appendix C. Financing:
AEMO *2025 Inputs, Assumptions and Scenarios Report*. Electricity paths: researcher-defined screening scenarios
informed by CSIRO–AEMO GenCost 2025–26. Monetary basis: real 2026 AUD (USD2024 × 1.605586). Each parameter's
source is listed in `data/parameters.csv`; full documentation is in the paper's Table 2 and Supplementary Information.
